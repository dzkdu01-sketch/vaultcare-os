## 零、生意背景

阿联酋卖成人用品，**你是供应商的分销**。7 个 WooCommerce 独立站（多域名投放），货盘在阿联酋发货，**客人基本货到付款**。
一天约 5 单；供应商一个月几次上新下架。中台是 `vault-os.site`。

---

## 总原则

**全程自动，我不做任何参与和干涉。**

自动抓取供应商的所有商品（标题、SKU、图片、视频、价格等）**文案价格照抄** →
相册主图加工为 800×800 → 自动转图片格式 → 自动换成 https → 自动同步到所有网站。

**这一条优先于下面所有细节。** 任何需要我点一下、上传一个文件、确认一下的环节，都算没做到。

## 界面要求

### ① 苹果风（macOS 风）

| 项 | 值 |
|---|---|
| 底色 | `#F5F5F7`（浅灰，不是纯白） |
| 卡片 | `#FFFFFF`，圆角 12–16 |
| 主文字 | `#1D1D1F` |
| 次要文字 | `#86868B` |
| 强调色 | `#0071E3` |
| 分割线 | `#E5E5EA`（1px） |
| 阴影 | 基本不用 |
| 留白 | 要大 |

左边菜单 + 右边内容。信息密度够高（天天用的工具）。不要重阴影、渐变、密集表格风。

### ② 不许有说明性文字

默认全删，只留「没有它就用不了」的。

**删：** 教怎么用、解释为什么、预测会发生什么、技术名词（除非它就是必须填的字段名）。

**留：**

1. 状态和数据本身
2. 字段名 / 按钮名 / 表头 / 标题
3. 点了才弹的确认框、报错、成功提示
4. 会让人选错的关键信息

确认框里的**后果说明**保留（例如停用网站：停用不是删掉，记录都留着）。

### ③ 手机

全站手机：表单标签在上、输入全宽；sheet 近全宽、停在底栏上方；底栏不挡主按钮。
桌面表格不改结构。

### 订单列表（现行）

- 无「客户」列。
- 默认筛「待处理」。
- 不要状态下拉。用「待处理 / 全部」分段。
- 手机整卡点击进详情。
- 手机待处理单：「详情」改为「标记已处理」，写入 `submitted`。已处理 / 已发货不再显示该按钮。
- 无黄条「共 N 单」。筛选行可有灰色计数。
- 手机：无站点 pill、不重复堆总价。站点用一行文字/链接即可。
- 桌面表格：网站订单号 / 网站 / WhatsApp / 商品 / 状态 / 金额 / 日期 / 详情。行点击进详情。

### 订单详情（现行）

- 商品表：编号 / 数量 / 单价 / 小计。无「名称」列。
- 无「①录进供应商系统」。
- 确认函内联（文字 + 复制 + 下载图片）。
- WhatsApp 预填确认函文本。
- 确认函含 `City:`。
- 无「状态变更记录」区块。
- 地址可点开 Google 地图。查询：地址 + 城市 + `United Arab Emirates`。
- 空地址显示「-」，不可点。无地址、有城市时，城市可点地图。
- 状态分段：待处理 / 已处理 / 已发货（界面若仍写「已录入」，对应同一字段 `submitted`）。
- 订单不设删除。假单、重复单「取消」，取消的单能恢复。

### B15：订单编辑能改什么

| 区块 | 字段 | 能不能改 |
|---|---|---|
| 客户 | 姓名、WhatsApp、电话、邮箱、城市、地址、客户备注 | 能 |
| 商品 | 加 / 删 / 改数量 | 能 |
| 金额 | 实收 | 能（抹零、折扣） |
| 金额 | 商品合计 | 只读，自动算。和实收不一致时显示「已优惠多少」 |
| 这一单 | 来源网站、网站订单号 | 能 |
| 这一单 | 下单时间、付款方式 | 只读 |
| 我的 | 我的备注、状态 | 能 |

改了商品或实收之后，确认函和给供应商的文本必须跟着变。
手工补单页字段必须和编辑页逐项一致。

**和 A3 的区别：** 订单里的商品明细能改；产品页的标题 / 描述 / 价格不能手改。相册主图由系统加工为 800×800，也不能在产品页手改。

### B16：岔路硬要求

| # | 硬要求 |
|---|---|
| **B16-1** | 新建页和编辑页字段必须逐项一致 |

| **B16-7** | 停用的对象，历史数据照样查得到 |

详测表见 `测试规则-岔路矩阵.md`。

### 供应商下单表单要填的字段

| 区块 | 字段 |
|---|---|
| 表头 | `Order number` = **网站订单号**（不是中台号）；再加一行「订单来源网址」 |
| Customer | `name`、`phone`、`whatsapp`、`city`、`address` |
| Order details | `code` ｜ `numb` ｜ `totle`。中间 `p…` 列忽略 |
| 底部 | `Total Price`、`note`。不要 Expedited Fee |

`address` 填文字地址，不买地图服务。详情页用 Google 地图搜索链接即可。
`phone` 和 `whatsapp` 是同一个号的两种写法，中台自动转。
确认函和现成文本都用网站订单号。老单不回捞，只做最近一周。

新单收单时必须存客户备注。本机库是旧数据，不等于线上 7 站配置。

## 四、素材

7 个站共用一套素材。同一服务器。图片 **webp**、视频 **MP4**。

**定案：** 只维护一份源（按编号命名：`VC459-1.webp`、`VC459-S1.mp4`），同步时自动分发到 7 个站。
相册主图统一 **800×800** 白边 contain；描述内嵌图仍原尺寸。
不要硬做「字面外链同一张图」—— WooCommerce 会自己再下一份，主图/缩略图会缺。

视频必须 https。描述里的图和视频要一起搬（A16）。

## 九、现行界面规则

### 商品列表

- 范围下拉（全部 / 没推全）已去掉。默认全部。
- 默认每页 100（可选 50 / 100 / 150）。
- 手机卡无「选择」、无「对照」。点卡片进详情。
- 桌面表格保留勾选和「对照」。
- 顶栏「立刻读一次」改为「日报」，进 `/products/daily`。
- 不要绿条：「还没读过供应商 / 这次变了什么 / 今天的日报」。
- 搜索：边输入边筛。编号 / 名称 / 标签 / 分类（也认供应商编码）。不区分大小写。
- 「供应商」按钮：打开供应商商品页。**有货源链接才显示入口。** 不要写死某个字段一定有值。
- 手机隐藏「停用站点」「补货进度」顶栏。桌面保留。

### 供应商 / 设置

- 供应商可配 `feed_url`（商品清单地址）。
- 设置去掉汇率。
- 网站设置弹层：手机全宽、标签在上、输入全宽。
- 三个旧供应商 qr/LY、VIP/VIP、自营/VC 不再预置。

### 日报

- 各站推送失败商品（`failed`，列出 SKU / 名称 / 原因）
- 总览：已接入站数、在线合计、推送失败合计

通道没配也落库。页面可「现在生成一条 / 重新读一次」。
